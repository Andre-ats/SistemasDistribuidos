function Show-FirstLogBlock {
    param(
        [string]$Service,
        [string]$Marker,
        [int]$Lines = 22
    )
    $log = @(docker compose logs --no-log-prefix $Service)
    $index = -1
    for ($i = 0; $i -lt $log.Count; $i++) {
        if ($log[$i] -like "*$Marker*") {
            $index = $i
            break
        }
    }
    if ($index -ge 0) {
        $last = [Math]::Min($index + $Lines - 1, $log.Count - 1)
        $log[$index..$last]
    } else {
        Write-Host "Marcador não encontrado: $Marker"
    }
}

function Show-LastLogBlock {
    param(
        [string]$Service,
        [string]$Marker,
        [int]$Lines = 22
    )
    $log = @(docker compose logs --no-log-prefix $Service)
    $index = -1
    for ($i = 0; $i -lt $log.Count; $i++) {
        if ($log[$i] -like "*$Marker*") {
            $index = $i
        }
    }
    if ($index -ge 0) {
        $last = [Math]::Min($index + $Lines - 1, $log.Count - 1)
        $log[$index..$last]
    } else {
        Write-Host "Marcador não encontrado: $Marker"
    }
}

PARTE 5 — REPLICAÇÃO, SINCRONIZAÇÃO E RECUPERAÇÃO
======================================================================

IMPORTANTE
- Execute os comandos na mesma janela do PowerShell do VS Code, dentro da pasta do projeto.
- As variáveis $RID e $blocoRep são usadas em comandos seguintes. Não feche o terminal entre essas etapas.
- Não execute "docker compose down -v" durante esses testes: isso apagaria os volumes persistidos.
- Os comandos abaixo mantêm os mesmos serviços e diretórios usados no roteiro original.

1) O servidor manda a mensagem para os outros (tópico replication)

Este bloco procura o primeiro evento ENVIANDO PUB que contenha Type: replicate_post e mostra o evento completo:

$logServer1 = @(docker compose logs --no-log-prefix server1)
$blocoRep = $null

for ($i = 0; $i -lt $logServer1.Count; $i++) {
    if ($logServer1[$i] -match 'ENVIANDO PUB') {
        $fim = [Math]::Min($i + 25, $logServer1.Count - 1)
        $candidato = $logServer1[$i..$fim]
        $texto = $candidato -join "`n"

        if ($texto -match 'Type:\s*replicate_post') {
            $blocoRep = $candidato
            $blocoRep
            break
        }
    }
}

if (-not $blocoRep) {
    Write-Host "Não encontrei ENVIANDO PUB com Type: replicate_post em server1."
}

2) Guardar o ID dessa mensagem

O roteiro original procura um campo no formato Id=... . Este comando aceita também Id: ...:

$RID = $null

if ($blocoRep) {
    $textoRep = $blocoRep -join "`n"
    if ($textoRep -match 'Id[=:]\s*([^,\s]+)') {
        $RID = $Matches[1]
    }
}

Write-Host "RID = $RID"

Se $RID ficar vazio, confira o bloco da etapa 1: talvez o ID esteja em outro formato ou não exista nesse evento. Não avance para a etapa seguinte até localizar o ID.

3) Outro servidor recebendo a mesma mensagem

$logServer2 = @(docker compose logs --no-log-prefix server2)
$blocoRecebido = $null

if ($RID) {
    for ($i = 0; $i -lt $logServer2.Count; $i++) {
        if ($logServer2[$i] -match 'RECEBENDO PUB') {
            $fim = [Math]::Min($i + 25, $logServer2.Count - 1)
            $candidato = $logServer2[$i..$fim]
            $texto = $candidato -join "`n"

            if (($texto -match 'Type:\s*replicate_post') -and $texto.Contains($RID)) {
                $blocoRecebido = $candidato
                $blocoRecebido
                break
            }
        }
    }
}

if (-not $blocoRecebido) {
    Write-Host "Não encontrei em server2 a mensagem replicate_post com o ID $RID."
}

9) Verificar se todos os servidores possuem os mesmos dados

O comando abaixo calcula uma assinatura MD5 agregada dos arquivos de cada diretório /data/serverN, dentro do próprio container:

1..8 | ForEach-Object {
    $s = "server$_"
    $resultado = docker compose exec -T $s sh -c "cd /data/$s && md5sum * | md5sum"
    $hash = ($resultado | Select-Object -Last 1).ToString().Trim()
    Write-Host "${s}: $hash"
}

Interpretação:
- Se os oito hashes forem iguais, os conteúdos agregados dos arquivos comparados são idênticos.
- Se algum hash for diferente, não conclua que a replicação falhou imediatamente: compare também a lista de arquivos e os logs de sincronização para identificar a diferença.
- O teste pressupõe que os diretórios tenham arquivos e que o comando md5sum esteja disponível nos containers.

Opcional — iniciar novamente os clientes depois da comparação:
docker compose start client1 client2 client3 client4 client5 client6 client7 client8
